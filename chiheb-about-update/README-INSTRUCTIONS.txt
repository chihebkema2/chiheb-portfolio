Upload about.html and sitemap.xml to the ROOT of chihebkema2/chiheb-portfolio on GitHub using Add file > Upload files. Commit to main. The existing styles.css and assets directory are used and must remain untouched.

To link to the new page from your Home page, edit index.html in GitHub:
Replace <a href="#about">About me</a>
With    <a href="about.html">About me</a>
Also, if desired, add a link in your existing About section to about.html.

After publishing, check https://chihebkemaoun.pages.dev/about.html and https://chihebkemaoun.pages.dev/sitemap.xml.
Then submit sitemap.xml again to Google Search Console if needed (resubmission is optional; Google periodically refetches).
